# ✨ Smart Event Dashboard

A modern and interactive **Smart Event Dashboard** built using **pure Vanilla JavaScript**, HTML, and CSS.

This project demonstrates real-world **DOM manipulation, event handling, dynamic UI rendering, event delegation, and localStorage integration** — without using any external libraries or frameworks.

---

## 🚀 Live Features

✅ Add new events dynamically  
✅ Delete events  
✅ Mark events as completed  
✅ Data persistence using localStorage  
✅ Responsive card layout  
✅ Modern Glassmorphism UI  
✅ Empty state handling  
✅ Real-time event counter  

---

## 🧠 Learning Objectives Covered

- DOM traversal and selection
- Dynamic element creation
- Event handling
- Event delegation
- Text manipulation:
  - `innerText`
  - `innerHTML`
  - `textContent`
- Style manipulation using JavaScript
- Debugging with browser DevTools
- LocalStorage for data persistence

---

## 🛠️ Tech Stack

- **Vanilla JavaScript**

❌ No external libraries
